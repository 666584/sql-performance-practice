# SQL 연습 저장소

이 저장소는 백엔드 개발 역량 강화를 위한 SQL 문제 풀이 및 학습 기록 공간입니다.

단순 문법 암기가 아니라,  
데이터를 어떻게 구조적으로 사고하고 효율적으로 조회할 것인지에 집중합니다.

---

## 🎯 목적

- SQL 문제 해결 능력 향상
- 데이터베이스 기본기 강화
- 쿼리 최적화 감각 익히기
- 기술 면접 대비

---

## 📚 학습 범위

- 기본 SELECT 문
- JOIN (INNER, LEFT, RIGHT)
- GROUP BY 및 집계 함수
- 서브쿼리
- 윈도우 함수
- 인덱스와 성능 최적화
- 실전 면접 유형 문제

---

## 🛠 사용 환경

- MySQL

---

## 📂 디렉토리 구조

/select  
/join  


각 폴더에는 다음이 포함됩니다:

- 문제 설명
- SQL 풀이 코드
- 풀이 과정 및 설명

지속적인 연습을 통해
